# P5 Open-source and dataset research

Research snapshot: 2026-10-29. This is a source review, not a legal opinion. Dataset licenses, terms and revision availability must be rechecked before each new download or release. No audio, HEF or model weights were downloaded for this phase.

## Summary and selection

The intended first benchmark is **Mozilla Common Voice Scripted Speech 27.0**, locales `zh-TW` and English, ASR task. Mozilla's current catalog lists Chinese (Taiwan) as CC0-1.0 and MP3. The dataset is not copied or mirrored: Mozilla's current legal terms state that datasets are provided through Mozilla Data Collective (MDC), and ask users not to post, distribute or mirror the data elsewhere. Mozilla's dataset FAQ says an email address is required to download. Therefore this checkout did not request, download, or use Common Voice audio. Owner action is required: provide an approved contact email and personally access MDC, accept the applicable terms, then place only authorized samples in the ignored local directory described in [P5 ASR evaluation](P5_ASR_EVALUATION.md).

FLEURS is a publicly visible alternative under CC BY 4.0. The current Hugging Face dataset revision has `en_us`, `cmn_hans_cn` (Mandarin/China), and `yue_hant_hk` (Cantonese/Hong Kong), but **no zh-TW Mandarin configuration**. We did not substitute simplified Mandarin or Cantonese data and mislabel it as Taiwan Traditional Chinese. If Mozilla access is not approved, Owner may authorize a separately labelled FLEURS `cmn_hans_cn` benchmark, but that would not satisfy the zh-TW cohort.

## Access and selection decision

1. Use Common Voice `zh-TW` and English only after Owner provides/uses an approved email and completes the official MDC access/terms flow. Keep the downloaded release version, MDC item ID, source clip IDs and file SHA-256 in the local-only manifest.
2. Do not transfer raw audio or full corpora into Git, reports, cloud storage or the public repository. A local report contains only selected IDs, hashes, aggregate metrics and categorized failures.
3. If Common Voice access is unavailable, pause the zh-TW/English comparison or ask Owner to authorize a separately labelled FLEURS Mandarin-China + English fallback. Do not describe that fallback as Traditional Chinese or spontaneous code-switch.
4. Keep CS-Dialogue research-only. It is not part of the benchmark manifest and was not downloaded.
